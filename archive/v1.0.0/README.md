# ArtefactsOrthoMaker v1.0.0

This directory preserves the released v1.0.0 application, its shared core and the dependency and validation files. Run `python app.py` from this directory using the archived `requirements.txt`. This version uses its own `input/` and `output/` alongside its `app.py`.

See the [v1.0.0 tag](https://github.com/kotdijian/ArtefactsOrthoMaker/tree/v1.0.0) for the complete release tree and original documentation. The [MIT license](../../LICENSE) applies to this version.
